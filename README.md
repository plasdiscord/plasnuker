## **Overview**
**PLAS NUKER** is a world-class, multi-threaded tool built for system administration, server recovery, and extreme stress testing. Leveraging the power of `asyncio` and `aiohttp`, PLAS provides unparalleled speed and efficiency in managing large-scale Discord environments.

## **Key Features**

### **Aggressive Management**
*   **Full Nuke:** Wipe channels, roles, and profiles in seconds with optimized concurrency.
*   **Auto Raid:** High-speed channel creation and automated mass-messaging.
*   **Mass Actions:** Ban, Kick, Mute, or Unban every member simultaneously.

### **Server Transformation**
*   **Channel Mastery:** Mass delete, create, or rename channels and categories.
*   **Role Engineering:** Strip roles from members or create dozens of custom roles instantly.
*   **Profile Editing:** Change server name, icons, and descriptions via automated tasks.

### **Stealth & Utility**
*   **Ghost Pinging:** Tag members and vanish without a trace.
*   **Impersonation:** Send messages via webhooks mimicking any user.
*   **Webhook Warfare:** Deploy and spam high-frequency webhooks across all text channels.
*   **Voice Control:** Mass move members, deafen, or disconnect users from voice channels.

## **Visual Interface**
PLAS NUKER features a stunning **Colorama-powered CLI** with:
*   **Glitch Effects:** Cyberpunk-style text transitions.
*   **Real-time Progress Bars:** Track task completion with precision.
*   **Dynamic Banners:** ASCII art that adapts to your terminal size.
